# Сервер

## Файлы проекта

- **main.cpp.**
  Файл в котором прописана логика получения информации от телефона к серверу, а так же при помощи библиотеки ImGui написано небольшое приложение для отображения полученной информации.

## Submodules

- **ImGui.**
  Библиотека для построения графических интерфейсов.

- **Implot.**
  Расширение для ImGui, которое добавляет виджеты для визуализации данных в виде 2D-графиков.

- **Glfw.**
  Это библиотека для создания окон, управления контекстами OpenGL (или Vulkan) и обработки ввода.

- **Android-project.**
  Это submodule самого андроид приложения.
